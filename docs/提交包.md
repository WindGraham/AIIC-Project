您好。这是我们参加「AI 模拟面试官」项目挑战的提交材料。

**产品定位**：我们做的不是"AI 问答"，而是 **AI 面试官平台**。学员在这里预约一场针对某公司/某岗位的面试 → 进入真实面试间（文字对话/按住说话/真实全双工语音 + 视频房间 + 手撕代码 + 看屏）→ 按**明确的状态机**被一位 AI 面试官逐环节提问（自我介绍 → 介绍项目 → 提问项目 → 提问其他能力/知识 → 提问对岗位的看法 → 手撕代码 → 收尾）→ 结束得到**可执行的差评报告**（缺了什么、面试官想听到什么、下一步怎么练），且全程转写可下载、可分享、可复习。

三个"比 ChatGPT 更好"的差异化：
1. **人格分层**：可选 同级 / 资深同级 / 主管 面试官，语气与出题风格不同。
2. **跨场记忆/学习曲线**：每场结果落库，下一场注入你上次的薄弱项；报告页有多场趋势 + 重练入口。
3. **按岗位自动配题**：岗位技术栈/关键词 → 算法 tag → 题库（离线 150 题）匹配合适的手撕题。

**如何体验（1 分钟上手）**：
1. 打开 <https://mock.windgraham.art>，注册/登录。
2. 「管理简历」上传一份简历（PDF/Word/Markdown/TXT/Excel，系统自动解码）或粘贴文本。
3. 「预约面试」选简历/公司/岗位/JD/时间/是否手撕/面试官人格/面试方案（文字或语音）。
4. 进入「面试列表」→ 开始面试。纯文字流最直观：一句一句对话，右上角实时显示"当前环节"。

**交付物**：

**技术栈**：Next.js 16 + FastAPI + Pydantic；LLM=DeepSeek，视觉=Gemini，STT=Volcengine，TTS=MiniMax；信息搜索=多引擎+牛客+小红书/知乎（真实浏览器）；题库=离线 LeetCode-CN 150 题；数据存独立盘 SQLite。视频房间基于 livekit-meet 同款组件（自托管 LiveKit），真实摄像头/麦克风/共享屏。
