## 一句话
**我们做的不是"AI 答题"，而是"AI 面试官"——一个真实、完整、有针对性的模拟面试平台**：学员预约一次针对某公司/某岗位的面试，进入真实面试间（语音对话 / 手撕代码 / 共享屏幕），AI 面试官实时提问、追问、打分，结束后给一份**可执行的评价报告**（缺了哪些点、面试官想听到什么、下一步怎么练），且**全程转写 + 分享链接 + 语音回顾**。

## 洞察：市面 AI 模拟面试缺三件事
1. **流程不完整**：大多是一次性"问答→打分"，没有从预约、简历、真实面试场景到报告、转写、分享的完整闭环。
2. **信息不充分**：AI 只会问通用题，不知道目标公司/岗位**到底怎么考、考什么**（这是 AI 面试官最大的短板）。
3. **反馈不可执行**：只给一个总分，不给"你到底缺什么、我想听到什么、该怎么练"。

我们把这三点在一个平台上解决。

## 做了什么（交付物）
- **账号与平台闭环**：登录（注册/登录，本地账号+密码，SQLite 存于独立数据盘 `/data/probedesk`，不占系统盘）；管理简历（多份/默认/技能画像）；预约（选简历/公司/岗位/JD/时间/是否含手撕/场景含保研/**面试官人格**/**面试方案**）；面试列表（多场 + 距开始倒计时，可提前进入、AI 到点才进）。
- **预约 → 面试**：填简历 + 岗位 JD + 目标公司 + **面试方案(真实对话/按住说话/文字对话)** → 生成一场真实的面试（见下）。
- **真实、有时间概念的面试流程（核心）**：AI 面试官**真的在主持面试**，而非"后台搜题一个个丢给候选人"。约 60 分钟 = **40 分钟聊项目/经历/基础 + 20 分钟手撕代码**（可配置）。开场让你**自我介绍 → 挑一个你简历上的具体项目深挖 → 按你回答的长短与剩余时间逐层追问（架构/难点/取舍/数据/踩坑）→ 再结合岗位问基础与场景**。**每一轮都在后端重建一个 agent**，其 prompt 含：面试官身份(人格) + **你的简历** + **本场特殊要求(岗位/JD/场景/补充)** + **你和它全部的历史对话** + 时间预算。
- **三种面试方案（可预约时选，都走同一个 agent）**：①**真实对话(全双工)** 麦克风常开、边说边答、AI 实时语音（可打断）；②**按住说话(PTT)** 按住说话、松开识别，更稳定；③**文字对话** 打字一问一答，最稳最快。三者流程/追问完全一致，仅输入输出通道不同。
- **真实面试间**：`实时语音`（全双工/按住说话，流式 STT→大脑→流式 TTS 回放）+ `视频房间`（以 **livekit-meet 同款组件** `@livekit/components-react` 搭建，麦克风/摄像头/共享全屏正常，AI 面试官头像在场）+ `手撕代码`（本地题库**按岗位自动配题**，AI 实时读码判分并给提示阶梯）+ `让 AI 看我的屏幕`（Gemini 视觉理解共享画面）。
- **功能测试 = 真实房间**：`/self-test` 是与真实面试**完全相同**的房间（仅 AI 不出场），用户在房间内自测麦克风/摄像头/共享屏，下方带题目 + 代码书写区——正式面试前把所有设备调好。
- **信息充分**：Researcher 层在预约时检索（多引擎 + 牛客面经 + Tavily + **小红书/知乎（真实浏览器登录态采集）**）→ 结构化**岗位画像**（技能 / 考察点 / 公司面试流程 / 高频题），注入出题，问得"像真的懂这家公司"。
- **三个"比 ChatGPT 更好"的差异化**：
  - **人格分层**：预约时选 `同级 / 资深同级 / 主管`，决定面试官语气、压迫程度与出题风格。
  - **跨场记忆 / 学习曲线**：每场结果（分项得分 + `missing_slots`）落库，下一场计划**注入你上次的薄弱项**；报告页有**多场得分趋势 + 薄弱项 + 重练入口**。
  - **按岗位自动配题**：把岗位"技术栈/关键词"映射到算法 tag，从 150 题题库**匹配合适的手撕题**，题源/难度显示在预约与面试里。
- **可执行反馈**：`interviewer_os` 在报告里给 `missing_slots → what_i_want_to_hear → 一句话建议`（带候选人原话证据）；**面试中不实时展示**（保留"面试官大脑"的神秘感与公正）。
- **转写 / 分享 / 录制**：问答转写可下载；**公开只读分享页** `/share/{id}` 可转发给他人评价；**语音回顾**把报告核心合成音频。

## 技术架构
Next.js 16（App Router）+ FastAPI + Pydantic；LLM=DeepSeek（OpenAI 兼容），视觉=Gemini（aixhan），STT=Volcengine（流式/一次性），TTS=MiniMax（流式/一次性）；信息搜索=多引擎聚合+牛客+Tavily+**Playwright 真实浏览器驱动小红书/知乎**；题库=离线 LeetCode-CN 150 题（不做运行时抓取）。账号/会话/简历/预约/报告存 SQLite（独立数据盘）。面试过程借鉴 DeepInterview 的 **prep→live→post**：prep 用计划+记分卡，**live 用"每轮重建的 agent"(liveflow) 主持**（真时间概念、逐层追问，非死板游标），**post 的记分卡仍用计划为每题打分**——**无硬状态机**、可优雅降级。反馈内核参考学长 ProjectProbe 的 `interviewer_os`。视频房间基于 **livekit-meet 组件库**（`@livekit/components-react`，raw `Room`+`enableCameraAndMicrophone`）对接自托管 LiveKit（`wss://voice.windgraham.art`）。已用 systemd 常驻（agent:8000 / web:3101）。

## 差异化
| 别人 | 我们 |
|---|---|
| 填空式问答 | 完整真实场景（登录→预约→真实面试间→报告/分享） |
| 通用模板题 | Researcher 注入岗位画像 + **按岗位自动配题**，问得准 |
| 只给总分 | `missing_slots → what_i_want_to_hear` 可执行，带证据 |
| 单一面试官 | 人格分层 + **跨场记忆/学习曲线**（越面越懂你） |
| AI 不看代码/屏幕 | AI 读码判分（提示阶梯）+ Gemini 读屏 |
| 无沉淀 | 转写 + 分享 + 语音回顾 + 多场趋势可复用 |

## 验证
- 全部能力用**真实 API** 跑通（DeepSeek / Gemini 视觉 / Volcengine STT / MiniMax TTS），TTS→STT 回环逐字一致。
- **小红书 / 知乎**：用用户提供的登录态 cookie，Playwright 真实浏览器导航搜索页并抽取结果（笔记/回答），实测返回真实相关面经/问答；无 cookie 或失败时**优雅降级**到 360/必应/百度/牛客，主流程不崩。
- **双 agent 自玩测试 harness**：候选人 agent ↔ 面试官 brain 纯文本互聊，量化覆盖/防飘/追问/反馈可执行；实测 strong 考生 92 分 vs weak 75 分（分数能拉开、反馈具体）。
- 边界回归（未知 id→404、畸形输入不崩、**未登录 401、越权 403、preparing 409**）全部通过；16+ 干净 commit；**经 subagent 集群对抗式审查**（前端/后端/端到端/测试）。
- 自研 vs fork：产品主体自研；参考 DeepInterview（架构）与学长 ProjectProbe（反馈内核），已在 README 注明。
