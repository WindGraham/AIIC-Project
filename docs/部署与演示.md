# 部署与演示指南

> 目标：把 ProbeDesk 部署到一个**公开可访问的云服务器**，能录 3 分钟 demo 视频。提交要求：**公开 URL + 在云服务器加 2 个 SSH 公钥**。

## 1. 预备
- 一台有公网 IP 的云服务器（或已有 `aiic.fomalhaut647.com` 的机器）。
- 需要把 **2 个 SSH 公钥**加到服务器 `~/.ssh/authorized_keys`（你的 + 协作伙伴/备用机器）。
- 本环境已生成一对公钥示例（见下），如需新增公钥：`ssh-keygen -t ed25519 -C "aiic"` 然后 `cat ~/.ssh/id_ed25519.pub` 再 `ssh-copy-id` 到服务器。

## 2. 运行后端（agent API :8000）
```bash
cd /root/AIIC-Project/apps/agent
python -m venv .venv && .venv/bin/pip install -e .
cp .env.example .env                 # 填 key
PYTHONPATH=src .venv/bin/python -m uvicorn agent.main:app --host 0.0.0.0 --port 8000
# 建议用 systemd / uvicorn 常驻：uvicorn ... & 或 pm2
```

## 3. 运行前端（web :3101）
```bash
cd /root/AIIC-Project/apps/web
export AGENT_API_URL=http://127.0.0.1:8000   # 同机
pnpm install && pnpm build && pnpm start
# 或开发：pnpm dev -p 3101
```
> 若 agent 与 web 分机：`AGENT_API_URL=http://<agent-host>:8000`（web 的 route handler / server component 会代理）。
> 反代到公网：Nginx/Caddy 把 `https://<domain>` → `127.0.0.1:3101`，加 HTTPS（demo 建议尽早）。

## 4. 申请域名/HTTPS（公开 URL）
- 解析域名（如 `probe.<你的域>`）到服务器 IP；Nginx + Let's Encrypt（certbot）配 HTTPS。
- `NEXT_PUBLIC_APP_URL=https://your-domain`。

## 5. Demo 视频脚本（前 30 秒 wow）
1. 首页 → 点击"预约模拟面试"，一句话 demo（"我要面字节后端"）。
2. 进房间：**AI 先用语音问第一题**（TTS 回放）—— 30 秒内的第一个冲击点。
3. 用手撕代码到 coding 环节：写代码 → 提交 → **AI 判分并给提示**。
4. "让面试官看我的屏幕" → AI 用 Gemini 读屏描述。
5. 结束 → **报告页**：总分 + missing_slots → what_i_want_to_hear。
6. 点"复制分享链接" → 打开 `/share/{id}`（公开只读转写+报告）。

> 保持 3 分钟节点清晰；文本基线扎实，语音/看屏/判码为加分项。
