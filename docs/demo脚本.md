# ProbeDesk · 3 分钟 Demo 脚本（录制指引）

> 目标：在 3 分钟内讲清「我们做的是 AI 面试官，不是 AI 答题」，并当场演示从预约→面试→报告→学习曲线的完整闭环，突出三个「比 ChatGPT 更好」的差异化。公开地址 https://mock.windgraham.art（已部署，systemd 常驻）。

## 录制前准备
1. 用真实浏览器登录一个演示账号（或现场注册）。确保麦克风可用（语音环节）。
2. 在 `/resumes` 预先存一份干净的简历（演示用）。
3. 预热：对演示公司先跑一场，让 Researcher 缓存命中（缩短「准备中」等待）。若第一次会显示「准备中」约 10–20s，可在 UI 上自然带过（"AI 正在检索这家公司的面经"）。
4. 屏幕 1280×720 左右，浏览器放大到合适比例。

## 0–0:30 · 首页 + 一句话定位（wow）
- 打开 `mock.windgraham.art`，念：*"这是 ProbeDesk——我们做的是 AI 面试官，不是 AI 答题。"*
- 快速扫系统状态条（LLM/视觉/语音/搜索已配齐），点进「预约面试」。

## 0:30–1:10 · 预约一次「针对性」面试（信息充分的证据）
- 在 `/booking`：选一份简历、填公司/岗位（如"字节跳动 · 后端开发工程师"）、粘贴一句 JD、选**面试官人格=主管**、勾选**含手撕代码**、选时间 → 提交。
- 念：*"它不是通用问答——它会针对目标公司/岗位出题。"*
- 点开「面试列表」，看到这场预约 + 倒计时，点「进入面试」。
- （可选展示 Researcher：如果前面预热过，这里很快；如果没预热，UI 会显示"AI 正在准备面试…"，可说"AI 正在检索这家公司的真实面经、高频题与考察点"。）

## 1:10–1:40 · 真实面试间（语音 + 手撕 + 看屏）
- 房间进入后 AI 语音开场（按住说话已可）；直接演示**打字回答**（更稳）或**按住说话**。
- 演示**手撕代码**：AI 按岗位配题（念出题源/难度），代码面板里写一段，点「提交给面试官」→ AI 读码判分 + 给提示阶梯。
- 演示**让 AI 看屏幕**：点「看屏幕」→ 共享一个含关键信息的窗口 → AI 读屏描述。
- 念：*"AI 真的在看你的代码、看你的屏幕，不是走过场。"*

## 1:40–2:25 · 可执行报告（interviewer_os，只在报告展示）
- 进 `/report/{id}`：看综合得分 + 分项 + `面试官想重点听的`（missing_slots → 为什么在意 → 我想听到 → 一句话建议）。
- 强调：*"它不只会给总分，它会告诉你到底缺了什么、面试官想听到什么、下一步怎么练。"* 且**全程面试中不实时泄露**。
- 展示分享链接（`/share` 只读）与语音回顾（可播）。

## 2:25–3:00 · 三个差异化收尾 + 学习曲线
- 点「学习曲线」`/history`：看到**多场得分趋势 + 薄弱项 + 重练入口**；说明"下一场面试官会带着你上次的薄弱项来问你"（跨场记忆）。
- 念：*"人格分层、跨场记忆、按岗配题——这三个是它比 ChatGPT 更好的地方：它不只是一次性反馈，而是越面越懂你，还帮你构建进步曲线。"*
- 收尾：公开地址 / GitHub 就在描述里，欢迎试用。

## 兜底 / 准备
- 若语音/看屏因浏览器权限失败：明确提示并立即切下一环节，别卡住。
- 若「准备中」太久：切到已预热的那场，避免长等待。
- 备份：录制前把演示账号 + 一场已结束面试（有报告）准备好，保证报告页一定有数据。
